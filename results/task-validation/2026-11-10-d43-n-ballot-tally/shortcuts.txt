Shortcut attempts and single-rule deviations for n-ballot-tally 1.0.0.

Each attempt replaces bin/tally.py with the reference (tests/tallyref.py) changed as listed
(deviations.py in this folder holds the exact edits; S1 writes a stored copy of the correct
visible results), rebuilds out/tally.json from /app/data, runs the visible unit tests and
tools/check_tally.py as the agent would, and runs tests/verify.py for the reward. All runs were
made inside the task image (python:3.12-slim-bookworm, the pinned digest) on 2026-11-10 with
  docker run --rm -v <task>/tests:/tests:ro -v <this folder>:/r:ro <image> python3 -B /r/deviations.py
Counts are contests (7 visible, 10 in each held-out election) and rounds (31 visible).
"unit tests" in the verifier lines are the visible unit tests plus tests/hidden_cases.py.
