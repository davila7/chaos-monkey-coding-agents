Shortcut attempts and single-rule deviations for n-library-fees 1.0.0.

Each attempt replaces bin/fees.py with the reference (environment/gen/feesref.py)
changed as listed (deviations.py in this folder holds the exact edits), builds
out/statements.json from the visible period, runs the agent-visible unit tests and
tools/check_fees.py of a fresh build, and then runs tests/verify.py. All runs were
made inside the task image (python:3.12-slim-bookworm, the pinned digest, Python
3.12.15) on 2026-11-15 with `python3 -B deviations.py /task`. "visible unit tests"
and "check" are what the agent can see; the lines after them are the verifier.
"differ" counts statements (one per patron) or branch rows that are not equal to the
reference; "extra" counts statements for patrons the reference has none for.
