Fixed-width shipment layout FW1

Columns are 1-based and inclusive. Numbers are padded with zeros on the left,
text with spaces on the right.

  id        1-9    shipment id (SH and seven digits)
  type      10-10  record type: N new, C correction, V void
  shipped   11-17  ship date as YYYYDDD (year, then day of the year 001-366)
  weight    18-25  weight in grams, integer
  status    26-26  status code
  note      27-42  free text, ignored

Status codes:

  D  delivered
  L  delivered late
  C  cancelled
  R  returned
  H  held at depot

A void record has blanks in shipped and status and zeros in weight.
