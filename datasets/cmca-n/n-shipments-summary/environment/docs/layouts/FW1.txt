Fixed-width shipment layout FW1

Columns are 1-based and inclusive. Fields are padded with spaces on the right
or zeros on the left.

  id        1-9    shipment id
  shipped   10-16  ship date as YYYYDDD (year, then day of the year 001-366)
  weight    17-24  weight in grams, integer
  status    25-25  status code
  note      26-41  free text, ignored

Status codes:

  D  delivered
  L  delivered late
  C  cancelled
  R  returned
  H  held at depot

Lines starting with # are not shipments. The last line is #END followed by the
number of shipment lines.
