Fixed-width shipment layout FW2

Columns are 1-based and inclusive. Numbers are padded with zeros on the left,
text with spaces on the right.

  type      1-1    record type: N new, C correction, V void
  id        2-10   shipment id (SH and seven digits)
  shipped   11-18  ship date as YYYYMMDD
  weight    19-26  weight in hundredths of a kilogram, integer (00001250 = 12.50 kg)
  status    27-27  status code
  note      28-43  free text, ignored

Status codes are the same as in FW1:

  D  delivered
  L  delivered late
  C  cancelled
  R  returned
  H  held at depot

A void record has blanks in shipped and status and zeros in weight.
