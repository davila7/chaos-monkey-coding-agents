Fixed-width shipment layout FW2

Replaces FW1. Columns are 1-based and inclusive. Fields are padded with spaces
on the right or zeros on the left.

  id        1-9    shipment id
  status    10-10  status code
  shipped   11-17  ship date as YYYYDDD (year, then day of the year 001-366)
  weight    18-24  weight in hundredths of a kilogram, integer (0001250 = 12.50 kg)
  note      25-40  free text, ignored

Status codes are the same as in FW1:

  D  delivered
  L  delivered late
  C  cancelled
  R  returned
  H  held at depot

Lines starting with # are not shipments. The last line is #END followed by the
number of shipment lines.
