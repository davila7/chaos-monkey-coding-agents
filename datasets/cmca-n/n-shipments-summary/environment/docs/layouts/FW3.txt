Fixed-width shipment layout FW3

Columns are 1-based and inclusive. Numbers are padded with zeros on the left,
text with spaces on the right. Record length: 41 characters.

  id        1-9    shipment id (SH and seven digits)
  shipped   10-16  ship date as YYYYDDD (year, then day of the year 001-366)
  type      17-17  record type: N new, C correction, V void
  weight    18-24  weight in tenths of a pound, integer (0001255 = 125.5 lb)
  status    25-25  status code
  note      26-41  free text, ignored

Status codes are the same as in FW1:

  D  delivered
  L  delivered late
  C  cancelled
  R  returned
  H  held at depot

A void record has blanks in shipped and status and zeros in weight.
