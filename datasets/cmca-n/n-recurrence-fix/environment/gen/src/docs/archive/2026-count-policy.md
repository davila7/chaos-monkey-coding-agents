# Calendar policy: counting instances (withdrawn)

Status: withdrawn in release 4.0.0. Kept for the record; see `rules.md` 5.2
for the rule that applies.

1. A rule with COUNT shall produce COUNT instances that actually take place.
   Instances removed by an excluded date are not counted, so the rule
   produces a further instance in place of each one removed.

2. Extra dates are not counted.

3. Rationale: organisers who cancel one meeting of a series of ten expected
   the series to still hold ten meetings.
