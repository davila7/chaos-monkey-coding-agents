\section{Reproduction}

Every number in this paper is generated from release \code{2026-11-18-m6} by the command
\begin{center}\code{python -m cmca\_analysis paper -{}-release results/2026-11-18-m6 -{}-out paper/generated}\end{center}
and \code{paper/build.sh} rebuilds the PDF; the release report \code{reports/2026-11-18-m6-release.md} lists the evidence directories and the commands that produced them.
Oracle and null-agent runs need no API key.
Trial runs need model API access and are not required to check the paper.
