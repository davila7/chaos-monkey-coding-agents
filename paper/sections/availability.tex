\section*{Code and data availability}
\label{sec:availability}

Code, tasks, injectors, the conformance suite and analysis are at \url{https://github.com/davila7/chaos-monkey-coding-agents}.
The results in this paper are release \code{2026-11-18-m6} (directory \code{results/2026-11-18-m6}, git tag \code{m6-2026-11-18}); the pre-registration is tag \code{pre-m6-2026-11-10}; the schedule seed is \code{m6-2026-11-10}.
Trial-level records, tasks and trajectories are also published as a dataset at \url{https://huggingface.co/datasets/davila7/chaos-monkey-coding-agents}.
Every number, table and figure in Section~\ref{sec:results} is regenerated from the release by \code{python -m cmca\_analysis paper}, which needs no API key; rerunning trials needs model API access and spends money.
