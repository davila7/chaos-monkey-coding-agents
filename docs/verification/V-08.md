## Evidence after paid credits

- **The gateway retries failed requests on other providers.** The invalid image request made 4 provider attempts in order `anthropic`, `bedrock`, `vertexAnthropic`, `claudeaws`, all HTTP 400, although the error carries `isRetryable: false`. The same request with `only: ["anthropic"]` made 1 attempt. A successful request made 1 attempt. Routing metadata lists `bedrock`, `vertexAnthropic` and `claudeaws` as `fallbacksAvailable` for this model.
- `max_tokens` 999999 returned HTTP 200 with a normal answer: the gateway does not reject an out-of-range output limit.
- **fx can pin the provider.** fx 0.0.13 reads `FX_PROVIDER_ORDER` and `FX_PROVIDER_STRICT`. Captured agent requests carry `providerOptions.gateway` = `{"caching": "auto"}` by default, `{"caching": "auto", "order": ["anthropic"]}` with the order only, and `{"caching": "auto", "only": ["anthropic"]}` with both. `ChaosFx` now sets both from the provider prefix of the model id.
- fx also sends one title request per session (`maxOutputTokens` 128, no tools) with no `providerOptions`, so that request can still fall back. It is outside the agent loop.
- **Reasoning setting.** Captured requests (`results/conformance-s/2026-10-15-gateway/reasoning-options.jsonl`, same arithmetic prompt in every run): Claude Code 2.1.289 sends `thinking: {"type": "adaptive", "display": "omitted"}` and `output_config: {"effort": "medium"}` both by default and with `--effort medium`. fx sends no `reasoning` field by default and `reasoning: "medium"` with `effort` set to `medium` in `settings.json`; the gateway response reported 410 reasoning tokens without the setting and 368 with it, so the gateway applies thinking either way. How the gateway maps `reasoning: "medium"` onto Anthropic's request is not visible from the client. The owner chose to pin `medium` on both configs (D-0029).
- **fx usage is copied before billing settles.** In the step 8 trial, `usage-v2.json` had `billing: "pending"`, counted 2 requests and $0.068602, and listed 6 generations as pending, while fx's `--json` output reported 132,978 input and 2,362 output tokens. Looking up the pending generations at `GET /v1/generation?id=<id>` gave $0.0445524 more. `ChaosFx` now resolves pending generations on the host and reports no cost when a lookup fails. A generation record can lag: one appeared after 10 seconds, another still returned 404 after more than 10 minutes, so the lookup waits about three minutes per record before giving up. The trial's corrected totals: 132,978 input tokens, 2,362 output tokens, 101,209 cache read tokens, $0.1131544; reward 1; `resolved_provider` `anthropic`.

## Pi and OpenCode request bodies (2026-10-18, no model API)

Both harnesses ran in containers against a local stand-in for the Anthropic Messages API that logs each request body (`docs/verification/V-24/fake-model.mjs`; method in V-24 and V-25).

- Pi 1.0.3, `--provider anthropic --model claude-sonnet-5-5 --thinking medium` (the `pi-claude` setting): model id `claude-sonnet-5-5`, `thinking` adaptive with `display: "summarized"`, top-level `output_config.effort` `high`, and a trailing mid-conversation `system` message with `output_config.effort` `medium` (`V-24/2026-10-18-pi-reasoning.txt`).
- OpenCode 1.18.35, `--model=anthropic/claude-sonnet-5-5 --variant medium` (the `opencode-claude` setting): model id `claude-sonnet-5-5`, `thinking` adaptive with `display: "summarized"`, `output_config.effort` `medium`; plus one tool-less request to `claude-haiku-5-5` with effort `low` per run (`V-25/2026-10-18-harbor-clean.txt`).
- Both send the `cc-claude` model id to the Anthropic API with no routing gateway in between. Client-side retries of failed model requests were not checked.
