## Evidence after paid credits

- **The gateway retries failed requests on other providers.** The invalid image request made 4 provider attempts in order `anthropic`, `bedrock`, `vertexAnthropic`, `claudeaws`, all HTTP 400, although the error carries `isRetryable: false`. The same request with `only: ["anthropic"]` made 1 attempt. A successful request made 1 attempt. Routing metadata lists `bedrock`, `vertexAnthropic` and `claudeaws` as `fallbacksAvailable` for this model.
- `max_tokens` 999999 returned HTTP 200 with a normal answer: the gateway does not reject an out-of-range output limit.
- **fx can pin the provider.** fx 0.0.13 reads `FX_PROVIDER_ORDER` and `FX_PROVIDER_STRICT`. Captured agent requests carry `providerOptions.gateway` = `{"caching": "auto"}` by default, `{"caching": "auto", "order": ["anthropic"]}` with the order only, and `{"caching": "auto", "only": ["anthropic"]}` with both. `ChaosFx` now sets both from the provider prefix of the model id.
- fx also sends one title request per session (`maxOutputTokens` 128, no tools) with no `providerOptions`, so that request can still fall back. It is outside the agent loop.
- **Reasoning setting.** fx sends no reasoning or thinking options for this model (the agent request has `maxOutputTokens` 128000 and only the gateway options above). `cc-claude` runs Claude Code 2.1.289 with Harbor's defaults (no `--effort`), so neither config pins a reasoning setting; `reasoning` is `"<setting>"` in both config files.
- **fx usage is copied before billing settles.** In the step 8 trial, `usage-v2.json` had `billing: "pending"`, counted 2 requests and $0.068602, and listed 6 generations as pending, while fx's `--json` output reported 132,978 input and 2,362 output tokens. Looking up the pending generations at `GET /v1/generation?id=<id>` gave $0.0445524 more. `ChaosFx` now resolves pending generations on the host and reports no cost when a lookup fails. The trial's corrected totals: 132,978 input tokens, 2,362 output tokens, 101,209 cache read tokens, $0.1131544; reward 1; `resolved_provider` `anthropic`.
