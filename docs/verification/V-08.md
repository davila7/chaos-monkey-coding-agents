## Documentation read (2026-10-15)

- Harbor 0.24.0 `harbor/agents/installed/fx.py`: `MODEL_CONNECTION` has `default_provider="vercel_ai_gateway"` and `api_key_envs=("AI_GATEWAY_API_KEY", "VERCEL_AI_GATEWAY_API_KEY")`; `run` raises unless `AI_GATEWAY_API_KEY` or `VERCEL_OIDC_TOKEN` is set. A `vercel_ai_gateway/` prefix on the model name is stripped and the rest goes to `FX_MODEL`.
- https://github.com/vercel-labs/fx lists AI Gateway, ChatGPT and Grok subscriptions, and OpenAI-compatible endpoints as providers. A direct Anthropic API key is not listed.
- Not yet tested against a pinned binary. Gateway retry behavior is not documented on these pages.

## Commands run (2026-10-15)

1. `curl -sS https://ai-gateway.vercel.sh/v1/models`, filtered for `sonnet-5`.
2. `curl -sS https://ai-gateway.vercel.sh/v1/chat/completions` with `AI_GATEWAY_API_KEY`, model `anthropic/claude-sonnet-5.5`, `max_tokens` 5.
3. `fx credits` and `fx models` inside the agent container.
4. One Harbor trial of `cmca_harbor:ChaosFx` on `s-p1-report` with the free model `openai/gpt-5.4-nano` (route check only, not a result).

## Evidence

- The gateway lists `anthropic/claude-sonnet-5`, `anthropic/claude-sonnet-5.5` and their `-batch` variants. The id uses a dot, not the dash of the plan text in D-0027; `configs/fx-claude.yaml` uses `anthropic/claude-sonnet-5.5`.
- The chat request returns HTTP 403, `type` `no_providers_available`, `name` `RestrictedModelsError`, message "Free tier users do not have access to this model. Upgrade to paid credits ...". The routing metadata resolves the provider to `anthropic`, so the id is valid and only the account tier blocks it.
- `fx credits` reported a balance of 4.13 (free credits); `fx models` listed 138 models.
- The nano trial ran end to end through the gateway: 90,586 input tokens, 1,000 output tokens, `cost_usd` 0.00697 read from the fx session (`usage-v2.json`).

## Still open

- The `cc-claude` model through the gateway with the same reasoning setting: blocked until the account has paid credits.
- Whether the gateway retries a failed model request: not tested. It needs the paid model and one deliberately failing request counted on both sides.
- Pi and OpenCode parts of this item: not started.

## Conclusion

Open. The fx route and the model id are confirmed; the model itself is blocked by the free tier.
