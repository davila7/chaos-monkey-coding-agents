## Item

Meta's terms for Muse Code on benchmarking and publication, and on using the harness with a non-Meta model (D-0046 item 3).

## Why it matters

`muse-claude` runs Meta's harness against Claude through a loopback endpoint. Creating a Meta API key to read the model catalog (needed by V-29, see below) is acceptance of these terms.

## Versions under test

Meta Model API Terms of Service, "Last updated: October 9, 2026", https://dev.meta.ai/legal/terms-of-service, fetched 2026-10-31. Meta Model API Acceptable Use Policy, https://dev.meta.ai/legal/acceptable-use-policy, fetched 2026-10-31 (no relevant clause). No separate Muse Code license is linked from https://dev.meta.ai/legal. Quotes below are verbatim.

## Findings

Scope. The preamble: the Terms apply to the Meta Model API "and any related software, tools or other components, including an artificial intelligence coding harness, Meta Model API keys, services, documentation, and content (collectively, with the Meta Models, the "Meta Materials")". Section 1: "Meta may make certain Meta Materials available for you to install on your device or systems ("Downloadable Materials")". The `muse` binary is a Downloadable Material.

Section 10.1, "You agree that you will not do any of the following in connection with use of the Services, unless applicable laws or regulations prohibit these restrictions (and then only after advance notice to Meta) or unless expressly permitted by Meta":

- (xiv) "copy or create any derivative works of any Downloadable Materials, sell, lease, publicly display, publicly perform, redistribute, sublicense, or otherwise make available any Downloadable Materials to any third party, or modify any Downloadable Materials, including any modification enabling any Downloadable Materials to operate with any model or service not provided by Meta".
- (xi) "publicly disseminate performance benchmarks or evaluations of the Services for the purpose of promoting or marketing a competing product or service, without Meta's prior written authorization".
- (ix), last sentence: "For the avoidance of doubt, using Services or Outputs solely for evaluation, benchmarking, or quality assessment of your own systems does not constitute a prohibited use under this Section".
- (x) "reverse engineer, decompile, disassemble, or otherwise attempt or assist others to derive the underlying models, harnesses, algorithms, weights, systems, or source code of the Services, including through systematic querying, model extraction techniques, reverse engineering, probing of inputs and outputs, or any other method designed to reconstruct or approximate the proprietary components of the Services".

## Reading

- `muse-claude` does not patch the binary; it sets a documented flag (`--base-url`, described in `muse exec --help` as "Override the provider base URL") and serves a catalog and the inference endpoint from loopback. Whether configuration counts as "modify" is a legal question this file does not settle. The clause names the purpose ("to operate with any model or service not provided by Meta") explicitly, and `muse-claude` has exactly that purpose.
- Publication of CMCA results is not for promoting a competing product, so (xi) does not apply on its face. A `muse-spark` config (Meta's own model) would be an evaluation of the Services and publishable under that reading.
- V-29 work so far (2026-10-31): the pinned binary was run in a container without network, its help text read, and its HTTP requests to a loopback stand-in logged; `strings` was used to look for the catalog format. That search was stopped once the catalog turned out to be undocumented, before these terms were read. Further format recovery from the binary would fall under (x); it is not continued.

## Observed behavior relevant to the decision (V-29, no model calls)

- Muse Code 1.4.14 (`1.4.14-R7309.1`, linux x86 sha256 `0809aac7cb58d18f5022b6d05e02aa1974683c0ec430e5f04d25b60ed17de2da`, matching Meta's release manifest). Providers: `echo`, `meta`, `local`.
- With `--base-url http://127.0.0.1:8787`, `muse exec` first sends `GET /muse-code/models` with the key as a bearer token and stops with "failed to fetch model catalog" when it gets no catalog. `https://api.meta.ai/muse-code/models` answers 401 without a key.
