## Item

Provider terms on automated use and publishing benchmark results (SPEC 15.3, D-0039 item 3).

## Why it matters

Legal and ethical publication. Every M5 config except `fx-claude` calls the Anthropic API with the project's commercial API key. `fx-claude` calls the model through Vercel AI Gateway with the project's Gateway key (D-0029).

## Versions under test

Terms pages as published on 2026-10-19 (dates below are the dates each page shows). Text copies were fetched on 2026-10-19 and kept outside the repository; quotes below are verbatim.

## Commands run

Pages fetched over HTTPS on 2026-10-19 and read in full. No model calls.

## Evidence

### Anthropic Commercial Terms of Service

https://www.anthropic.com/legal/commercial-terms, "Effective June 17, 2025".

- "Anthropic agrees that Customer (a) retains all rights to its Inputs, and (b) owns its Outputs".
- "Customer may not and must not attempt to (a) access the Services to build a competing product or service, including to train competing AI models or resell the Services except as expressly approved by Anthropic".
- No clause on benchmarking, evaluation or publishing results; no attribution requirement.

### Anthropic Usage Policy

https://www.anthropic.com/legal/aup shows "Effective November 12, 2026", which is after the read date. The version in force on 2026-10-19 is https://www.anthropic.com/legal/archive/22742366-2ef0-4c7a-a833-6523f10d3944, "Effective September 15, 2025".

- Both versions: "Utilize automation in account creation or to engage in spammy behavior".
- In force: "Utilization of inputs and outputs to train an AI model (e.g., “model scraping” or “model distillation”) without prior authorization from Anthropic".
- November version adds: "Agentic use cases must comply with the Usage Policy."
- Neither version has a clause on benchmarking or publishing results.

### Claude Code legal and compliance

https://code.claude.com/docs/en/legal-and-compliance, no date shown.

- "Developers building products or services that interact with Claude's capabilities, including those using the Agent SDK, should use API key authentication through Claude Console or a supported cloud provider."
- "The Claude Code binary must not be modified."
- "you can't use the Claude Code or Anthropic names or logos as part of your own product, feature, or company name ... or in a way that suggests Anthropic built, endorses, or is partnered with your product."

### Vercel Terms of Service

https://vercel.com/legal/terms, "Last Updated June 1, 2026". No benchmarking clause; incorporates the Acceptable Use Policy, the AI Product Terms and the API Terms ("The API terms apply to your access or use of the Services through APIs.").

### Vercel Acceptable Use Policy

https://vercel.com/legal/acceptable-use-policy, "Last Updated April 21, 2026".

- Section 2: "Further, customers on a non-Enterprise subscription may not: ... You may conduct benchmark tests of a service (other than AI Services (as defined below)). Any publicly disclosed results must include all necessary information for others to replicate the tests."
- Section 3 defines "Services that utilize artificial intelligence (“AI Services”)".

### Vercel AI Product Terms

https://vercel.com/legal/ai-product-terms, "Last Updated March 17, 2026".

- AI Gateway is listed among the AI Products and Services.
- "solely for Customer's personal or internal business use purposes".
- "The AI Products and Services may generate Output for you to deploy, copy, share, publish, or download for your use."
- Anthropic's terms pass through for Gateway calls to Anthropic models (https://vercel.com/legal/notices-and-license-information, "Last Updated February 26, 2026", lists "Anthropic : Commercial Terms of Service").

### Vercel API Terms

https://vercel.com/legal/api-terms, "Last Updated July 8, 2025".

- Users may not "use the API or any API Data to conduct performance testing of the Services without Vercel's express written permission".

## Conclusion

Anthropic route: closed. Automated runs with the project's commercial API key and publication of results are allowed. Conditions that apply to this project: no training or distillation on trial outputs, Claude Code binary unmodified (injection is by settings and hooks), product names in plain text with no logos or implied endorsement.

Vercel route: not cleared. AI Gateway is an AI Service, so the non-Enterprise benchmark permission does not cover it, and the API Terms require written permission for performance testing. Publishing `fx-claude` success, cost or call results measured through the Gateway can be read as benchmarking a Vercel AI Service. This is a reading of the published text, not legal advice. Per D-0039 item 3, `fx-claude` publication waits for the owner's decision; the other configs are not affected.
