## Item

## Why it matters

The analysis joins gateway records to trajectory calls by bare tool name, so it has to strip OpenCode's prefix. A failed MCP result that does not reach the trajectory would count as not delivered. The fixed axis needs the same thinking setting as `cc-claude` (SPEC 6.2).
