## Item

Token and cost accounting per harness in ATIF `final_metrics` or native logs

## Why it matters

Cost metrics: dollars per success and cost inflation (SPEC 11, M10) need one cost and token source per harness that analysis can read from committed job directories.

## Versions under test

- Harbor 0.24.0 (`harbor/agents/installed/claude_code.py`, `harbor/agents/installed/fx.py`), Claude Code 2.1.289, fx 0.0.13 through `cmca_harbor:ChaosFx`.
- Evidence: the 42 trials in `results/pilot/2026-10-14-cc-claude-clean-d26`, `results/pilot/2026-10-15-cc-claude-moderate-d26` and `results/smoke/2026-10-15-track-s`.

## Commands run

    # For every trial: result.json agent_result against trajectory.json final_metrics.
    python3 - <<'EOF'
    import json, glob
    for r in glob.glob('results/pilot/2026-10-1[45]*/*/*/result.json') + glob.glob('results/smoke/2026-10-15-track-s/*/*/result.json'):
        a = json.load(open(r))['agent_result']
        fm = json.load(open(r.replace('result.json', 'agent/trajectory.json')))['final_metrics']
        print(r, a['cost_usd'], fm['total_cost_usd'], a['n_input_tokens'], fm['total_prompt_tokens'], a['n_output_tokens'], fm['total_completion_tokens'])
    EOF
    grep -n "total_cost_usd\|litellm_estimate" .venv/lib/python3.12/site-packages/harbor/agents/installed/claude_code.py

## Evidence

- In all 42 trials, `result.json` `agent_result.cost_usd` equals `trajectory.json` `final_metrics.total_cost_usd`, and `n_input_tokens` and `n_output_tokens` equal `total_prompt_tokens` and `total_completion_tokens`.
- Claude Code: Harbor reads the `total_cost_usd` that Claude Code prints on its final `{"type":"result"}` stream line and falls back to a LiteLLM estimate only when that line is missing (`claude_code.py` lines 1004 to 1030 and 1626 to 1630). The per-step `metrics.cost_usd` values are LiteLLM estimates (`extra.cost_source: "litellm_estimate"`) and so is `agent_result.model_usage[...].cost_usd`. They differ from the reported total. In the first moderate trial (`results/pilot/2026-10-15-cc-claude-moderate-d26/cc-claude-moderate-a0/n-ledger-fix__CwFR9xQ`), the per-step estimates sum to $0.4315512 and `cost_usd` is $0.5487739, with the same token counts. Across the 36 `cc-claude` trials, the reported total is 1.10 to 1.42 times the estimate.
- fx: Harbor's `fx` agent copies the gateway usage before billing settles. Three of the six Track S smoke trials have `cost_usd: null` in `result.json` (D-0030). The settled per-trial cost is in `settled-usage.json` at the evidence root, keyed `<job>/<trial>`, field `settled_total_cost`. Token counts are present in `result.json` and `final_metrics` for all six trials.

## Conclusion

- Cost source per trial: `settled-usage.json` when the evidence root has one with a `settled_total_cost` for the trial; otherwise `result.json` `agent_result.cost_usd`. For Claude Code this is the harness's own reported total, not Harbor's estimate. `cmca_analysis` records the source per profile (`cost_sources`).
- Token source: `result.json` `n_input_tokens` plus `n_output_tokens`, which equal the ATIF `final_metrics` totals for both harnesses.
- Pi and OpenCode have not run benchmark tasks yet. Their accounting gets checked against this item on their first task runs.
