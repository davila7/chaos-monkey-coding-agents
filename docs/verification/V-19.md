## Conclusion

The differentiation claim holds in a narrower form than SPEC 3.2 states it. Wording supported by this evidence: "Prior fault-injection benchmarks inject faults into model-centric agent loops or simulators (ReliabilityBench, ToolMaze, AgentNoiseBench, ToolMisuseBench, PlanBench-XL), and developer tools inject faults at the LLM API or MCP layer of agents their users own (AgentBreak, AgentCheck, AgentChaos, Saboteur). Harness-Bench compares production harnesses but observes naturally occurring errors without injecting any. We found no work that applies one seeded fault schedule inside unmodified production coding-agent harnesses, at both the MCP layer and the harnesses' built-in tool layer, and compares harnesses under a fixed model." The claim is "we found no work", dated 2026-11-09, not "first".

SPEC 3.2 corrections (to record in DECISIONS.md with the paper work): Harness-Bench has no scored robustness dimension in v2; AgentCE-Bench injects no tool failures.
