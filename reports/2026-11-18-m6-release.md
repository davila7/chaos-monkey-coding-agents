# M6 release report

Release `results/2026-11-18-m6`, built from the D-0052 stage 1b to 4 evidence with the D-0055 analysis (curves on the curve subset, one counted trial per unit). It replaces `results/2026-10-31-m5-codex` as the release the site and the paper read; the M5 releases stay in `results/`. No model calls for this report.

## 1. What is in it

Ten configs (D-0051 item 2): Track S `cc-claude`, `codex-claude`, `fx-claude`, `opencode-claude`, `pi-claude`; Track N fixed model `cc-claude`, `codex-claude`, `fxh-claude`, `opencode-claude`, `pi-claude`. Model `claude-sonnet-5-5` in every config. Seed `m6-2026-11-10`.

- Leaderboard profiles `clean` and `moderate`, n = 3, on 37 Track S and 36 Track N tasks: 111 and 108 units per config and profile.
- Curve profiles `light` and `heavy`, n = 2, on 20 tasks per track (the stage 4 subset in the D-0052 progress notes).
- Units per config: Track S 302, Track N 296. 3,011 trial directories in all (`results/2026-11-18-m6/hf/meta.json`); 21 of them are originals that a delivery rerun replaces.

Evidence: `results/pilot/2026-11-11-m6-s`, `2026-11-12-m6-n`, `2026-11-16-m6-s3-{s,n}`, `2026-11-17-m6-s3a-{s,n}`, `2026-11-18-m6-s4-{s,n}`. Release command, from `python/cmca_analysis`:

      --evidence ../../results/pilot/2026-11-16-m6-s3-s --evidence ../../results/pilot/2026-11-16-m6-s3-n \
      --evidence ../../results/pilot/2026-11-17-m6-s3a-s --evidence ../../results/pilot/2026-11-17-m6-s3a-n \
      --evidence ../../results/pilot/2026-11-18-m6-s4-s --evidence ../../results/pilot/2026-11-18-m6-s4-n \
      --out ../../results/2026-11-18-m6
    uv run python -m cmca_analysis hf --release ../../results/2026-11-18-m6

## 3. Exclusions and reruns

A delivery rerun (METHODOLOGY 6) counts in place of its original, whatever a later check says about the original (D-0055 item 1). This settles one unit: `cc-claude` `n-split-reports` `moderate` attempt 2, whose original the D-0054 check now reads as delivered; the rerun counts.

Three units have no counted trial, because the original and its rerun both show an applied fault as not delivered:

- `cc-claude` `n-ledger-fix` `moderate` attempt 0: the persisted-output gap fixed by D-0054 after stage 2 (`reports/2026-11-12-m6-stage2.md`). `cc-claude` Track N `moderate` is 107 units, and pass^3 is not reported for it.
- `codex-claude` `n-log-rotation` `heavy` attempt 1: Codex rejects the command after the injector applied a fault (`reports/2026-11-18-m6-stage4.md` section 3).
- `opencode-claude` `s-cycle-count` `heavy` attempt 1: `empty` on an MCP 404 response shows as a tool error (same report).

Fault delivery per config and profile is in each `summary.json` under `profiles.<profile>.validity`, counted over every trial directory including replaced originals; the per-stage figures are in the stage reports.
