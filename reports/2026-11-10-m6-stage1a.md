# M6 stage 1a: validation, batch 1 calibration and cost gate

D-0052 stage 1a, run on 2026-11-10 in the cloud container. Not M6 data (D-0052 item 3). Every number below comes from the `summary.json` files in the evidence directories listed in section 1; costs are the harness-reported costs defined in METHODOLOGY 4.

## 1. What ran

| Block | Trials | Evidence |
|---|---|---|
| Validation: one batch 1 task per track, `clean`, attempt 0, each of the ten D-0051 configs | 10 | `results/smoke/2026-11-10-stage1-validate-{n,s}/` |
| Calibration: the 14 batch 1 tasks, `cc-claude`, `clean`, 5 attempts (D-0036 rule) | 70 | `results/calibration/2026-11-10-batch1-cc-claude-clean-{n,s}/` |
| Cost gate (SPEC 20): 5 batch 1 tasks per track, `clean` and `moderate`, 1 attempt, ten configs | 100 | `results/smoke/2026-11-10-m6-gate-{n,s}/` |

The gate tasks were drawn with `random.Random('m6-gate-2026-11-10').sample` over the 7 batch 1 tasks of each track: Track N `n-flaky-tests`, `n-recurrence-fix`, `n-semver-ranges`, `n-transit-boards`, `n-units-fix`; Track S `s-canary-promote`, `s-hotfix-backport`, `s-pagination-client`, `s-warranty-returns`, `s-webhook-signature`. Commands are in each directory's `commands.txt`.

Infrastructure: 2 of 180 trials failed before the agent ran (an image build in calibration, an `npm install` of Claude Code in the gate), 1.1%. Each was rerun once and passed (METHODOLOGY 6). Two earlier Track S validation attempts failed before any agent started, from setup errors on this host (relative config path, service images not built); they made no model calls.

## 5. Projection for stage 1b

Track S, 18 tasks x 5 configs x `clean` and `moderate` x 3 attempts = 540 trials, priced at the gate means per config with the 10% rerun allowance:

- Anthropic (`cc-claude`, `pi-claude`, `opencode-claude`, `codex-claude`): $0.538 per task, profile and attempt, $63.87 in total. D-0052 estimate: $72. It fits in the promotional credit ($159.85 before this stage, $131.61 after it).
- Vercel (`fx-claude`): $0.283 per task, profile and attempt, $33.56 in total. D-0052 estimate: $27, so 24% over. The Vercel credit was $37.37 before this stage and is about $29.06 after it, which does not cover the projection.
